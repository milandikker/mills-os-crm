# Mills OS CRM V1 Prototype

This folder contains the first working prototype shell for the custom CRM.

## What it shows

- Dark Mills OS visual language.
- Multi-business switcher.
- Unified inbox.
- Lead detail panel.
- Pipeline board.
- AI hub.
- Call log.
- Settings shell.

## What it is

This is a front-end prototype. It is meant to establish the structure, layout, and interaction model before live integrations are wired in.

## What it is not yet

- A connected backend.
- Real database storage.
- Live Meta / WhatsApp / phone integrations.
- Real AI model wiring.

## Files

- `index.html` — main CRM shell.
- `styles.css` — Mills OS visual system.
- `app.js` — simple interaction logic for switching business, view, and conversation.
